# Ayllon Works

Coming-soon site for [Ayllon Works](https://markjustfront.github.io/ayllon-works/) — 3D design and engineering.

The site is static HTML and CSS, hosted on GitHub Pages. There are no cookies, no analytics, and no third-party requests. The Jost typeface is self-hosted under the [SIL Open Font License](fonts/OFL.txt).
